# Citadel Spring Invitational Datathon

My submission for the Citadel Spring Invitational Datathon (April 2024). I collaborated with Arthur Chen, Shreyas Kaasyap, and Evan Semet as Team 8 for the competition. We placed 3rd with this submission that explores the predictive power of oil futures and posits their role as a strategic hedge in times of conflict.
